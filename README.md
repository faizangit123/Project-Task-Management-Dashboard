## 🗂️ Task Management Dashboard

A **Task Management Dashboard** built using **React, HTML, CSS, and JavaScript**.  
It designed to be reusable, easy to understand, and ideal for frontend practice and portfolio use.

![React](https://img.shields.io/badge/React-18-blue)
![Frontend%20Only](https://img.shields.io/badge/Backend-None-red)
![Responsive](https://img.shields.io/badge/Responsive-Yes-green)

- Semantic HTML and clean React component structure
- Client-side state management
- Optional localStorage persistence

## ✨ Features

- ➕ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as Completed or Pending
- 🎯 Assign priority (Low / Medium / High)
- 📅 Add due dates
- 📊 Dashboard task statistics
- 💾 Optional localStorage persistence
- 📱 Fully responsive design

---

## 📊 Dashboard Overview

- Total tasks count
- Completed tasks count
- Pending tasks count
- Optional progress indicator (percentage or progress bar)

---

## 🔍 Filtering & Sorting

- Filter tasks by:
  - Status (Completed / Pending)
  - Priority
- Sort tasks by:
  - Due date
  - Priority

## 🎯 Purpose of This Project

This project was built to:

- Practice frontend state management with React
- Build a real-world dashboard-style UI
- Demonstrate reusable component architecture
- Improve UI/UX design skills
- Create a portfolio-ready frontend project

---

## 🧰 Tech Stack

- **Frontend**: React, JavaScript (ES6+)
- **Styling**: CSS3 (Flexbox / Grid)
- **State Management**: React Hooks
- **Persistence**: localStorage (optional)
- **Build Tool**: Vite

## 🚀 Getting Started
Prerequisites

- Node.js (v18 or higher)
```
npm or yarn
```
**Installation**
```
npm install
```
**Run Development Server**
```
npm start
```
